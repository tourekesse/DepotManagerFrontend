| Champ | Valeur |
|-------|--------|

| **Plateformes** | Instagram Reels, TikTok, Facebook Reels |
| **Thème** | Pas de traçabilité des ventes cash |
| **Solution** | Caisse numérique + traçabilité |
| **Ton** | Dramatique → Soulagement |

---

## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:05)

| Champ | Détail |
|-------|--------|
| **Visuel** | Plan serré sur des mains qui comptent des billets de FCFA (5 000, 10 000) sur un comptoir en bois. Éclairage chaude, ambiance dépôt. |
| **Texton écran** | **"Tu vends... mais tu ne sais pas combien tu as RÉELLEMENT gagné"** |
| **Position texton** | Centre de l'écran, gros caractères blancs, ombre portée |
| **Voix off** | *"Chaque soir tu comptes... mais l'argent ne correspond jamais."* |
| **Musique** | Beat afro low-key, tension légère |
| **Transition** | Cut dur |

---

### SCÈNE 2 — LA RÉALITÉ (0:05 - 0:10)

| Champ | Détail |
|-------|--------|
| **Visuel** | Montage rapide (3 plans de 1-2 sec) : |
| **Plan 1** | Un billet de 10 000 F posé sur le comptoir |
| **Plan 2** | Une main d'employé qui prend le billet discrètement |
| **Plan 3** | Le comptoir vide, le patron regarde, perplexe |
| **Texton écran** | **"Les ventes cash n'ont pas de traçabilité"** |
| **Voix off** | *"Ton employé vend, prend l'argent... et toi, tu ne sais jamais."* |
| **Transition** | Fondu vers noir (0.5s) |

---

### SCÈNE 3 — LA SOLUTION (0:10 - 0:20)

| Champ | Détail |
|-------|--------|
| **Visuel** | Écran téléphone : interface caisse DepotManager |
| **Plan 1** (2s) | Le vendeur tape "Flag Speciale 33cl" dans la barre de recherche |
| **Plan 2** (2s) | Le produit apparaît, il clique "Ajouter au panier" |
| **Plan 3** (2s) | Le panier montre : 3 × 2 500 F = 7 500 F |
| **Plan 4** (2s) | Il clique "Valider" → animation de confirmation |
| **Plan 5** (2s) | Reçu qui sort de l'imprimante Bluetooth |
| **Texton écran** | **"Avec DepotManager : chaque vente est enregistrée"** |
| **Voix off** | *"Chaque vente, chaque franc, chaque transaction — tout est traçé. En temps réel."* |
| **Transition** | Slide vers la gauche |

---

### SCÈNE 4 — LE RÉSULTAT (0:20 - 0:26)

| Champ | Détail |
|-------|--------|
| **Visuel** | Patron détendu, assis sur son canapé chez lui. Il regarde son téléphone. |
| **Écran téléphone** | Dashboard DepotManager : "Ventes du jour : 487 500 F" en gros chiffres verts |
| **Expression** | Il sourit, satisfait |
| **Texton écran** | **"Le soir, tu sais exactement ce que tu as gagné"** |
| **Voix off** | *"Depuis ton téléphone, tu vois tout. Même à la maison."* |
| **Transition** | Fond noir progressif |

---

### SCÈNE 5 — CTA (0:26 - 0:30)

| Champ | Détail |
|-------|--------|
| **Visuel** | Fond noir. Logo DepotManager au centre. |
| **Texton 1** | **"DepotManager"** (gros, blanc) |
| **Texton 2** | **"L'œil du patron sur ton dépôt"** (sous le logo, orange) |
| **Texton 3** | **"🎁 Essai gratuit 14 jours"** (blanc) |
| **Texton 4** | **"🔗 depotmanager.com"** (bleu clair) |
| **Voix off** | *"DepotManager. L'œil du patron sur ton dépôt."* |
| **Musique** | Montée finale, beat positif |
