# 🎬 VIDEO 04 — TON STOCK TE MENT

## 📋 Fiche technique

| Champ | Valeur |
|-------|--------|

| **Durée** | 33 secondes |
| **Format** | 1080x1920 (vertical 9:16) |
| **Thème** | Stock inexact, casiers perdus |
| **Solution** | Suivi casiers + alertes |
| **Ton** | Dubitatif → Maîtrise |

---

## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:08)

| Champ | Détail |
|-------|--------|
| **Visuel** | Patron qui vérifie des casiers physiques empilés dans son dépôt. Il compte avec ses doigts, l'air dubitatif. |
| **Texton écran** | **"Tu penses avoir 200 casiers..."** |
| **Texton écran 2** | **"...mais tu n'en as que 160"** |
| **Voix off** | *"Ton stock sur le papier ne correspond jamais à la réalité."* |
| **Musique** | Tension légère |

---

### SCÈNE 2 — LES PERTES (0:08 - 0:13)

| Champ | Détail |
|-------|--------|
| **Visuel** | Montage : casiers empilés (certains vides, certains pleins). Un employé prend un casier sans l'enregistrer. |
| **Texton écran** | **"Les casiers partent. Tu ne sais pas lesquels."** |
| **Voix off** | *"Les casiers consignés, les emballages... tout part sans traçabilité."* |
| **Transition** | Fondu |

---

### SCÈNE 3 — LA SOLUTION (0:13 - 0:26)

| Champ | Détail |
|-------|--------|
| **Visuel** | Interface DepotManager |
| **Plan 1** (4s) | Écran stock : colonnes "Pleins" (vert) / "Vides" (orange) / "Alerte" (rouge). Casiers Flag Speciale : 12 (rouge = critique). |
| **Texton écran** | **"Stock en temps réel : Pleins, Vides, Alertes"** |
| **Voix off** | *"DepotManager suit chaque casier. Pleins, vides, consignés. Tout est compté."* |
| **Plan 2** (4s) | Notification popup : "⚠️ Stock critique : Flag Speciale 33cl — Plus que 12 casiers". Le patron clique "Ajuster". |
| **Texton écran 2** | **"Alerte automatique"** |
| **Voix off** | *"Quand le stock est bas, DepotManager t'alerte."* |
| **Plan 3** (5s) | Interface d'ajustement : le patron sélectionne le type de casier, entre la quantité, valide. "✅ Stock ajusté". |
| **Texton écran 3** | **"Ajustement en 1 clic"** |
| **Voix off** | *"Tu ajustes en un clic. Zéro calcul."* |
| **Transition** | Slide |

---

### SCÈNE 4 — CTA (0:26 - 0:33)

| Champ | Détail |
|-------|--------|

| **Texton 2** | **"DepotManager — Essai gratuit 14 jours — depotmanager.com"** |
| **Voix off** | *"DepotManager. Ton stock, toujours exact."* |
