## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:07)

| Champ | Détail |
|-------|--------|
| **Visuel** | Téléphone affichant "Aucune connexion réseau" (barre de signal barrée). Le vendeur essaie d'ouvrir une app de caisse classique. Message d'erreur. |
| **Texton écran** | **"Pas de réseau. Pas de vente. Argent perdu."** |
| **Voix off** | *"Le réseau tombe. Et avec lui, tes ventes."* |
| **Musique** | Tension, beats erratiques |

---

### SCÈNE 2 — LA SOLUTION (0:07 - 0:18)

| Champ | Détail |
|-------|--------|
| **Visuel** | Même téléphone, même "Pas de réseau". Mais l'app DepotManager s'ouvre normalement. |
| **Plan 1** (3s) | L'écran DepotManager fonctionne. Le vendeur ajoute "Flag Speciale 33cl" au panier. |
| **Texton écran** | **"DepotManager fonctionne HORS LIGNE"** |
| **Voix off** | *"Avec DepotManager, même sans internet, tu continues de vendre."* |
| **Plan 2** (4s) | Le vendeur valide la vente. Message : "✅ Vente enregistrée — Synchronisation en attente". |
| **Texton écran 2** | **"Vente enregistrée même sans réseau"** |
| **Plan 3** (4s) | Le réseau revient (barre de signal réapparaît). Animation : "🔄 Synchronisation... ✅ Synchronisé". |
| **Texton écran 3** | **"Tout se synchronise dès que le réseau revient"** |
| **Voix off** | *"La vente est enregistrée. Dès que le réseau revient, tout se synchronise. Zéro perte."* |
| **Transition** | Slide |

---
