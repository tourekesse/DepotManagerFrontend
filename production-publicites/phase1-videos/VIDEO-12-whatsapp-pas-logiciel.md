# 🎬 VIDEO 12 — WHATSAPP N'EST PAS UN LOGICIEL DE GESTION

## 📋 Fiche technique

| Champ | Valeur |
|-------|--------|
| **Titre** | WhatsApp n'est pas un logiciel de gestion |
| **Durée** | 38 secondes |
| **Format** | 1080x1920 (vertical 9:16) |
| **Thème** | Messages mélangés, pas de structure |
| **Solution** | Fiches clients structurées |
| **Ton** | Désordre → Clarté |

---

## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:10)

| Champ | Détail |
|-------|--------|
| **Visuel** | Écran téléphone : groupe WhatsApp "Dépôt Boissons". Des dizaines de messages mélangés : photos de reçus manuscrits, "J'ai vendu 3 casiers", "Kodjo passe demain", emojis, vocal de 2 min. Le patron scrolle frénétiquement. |
| **Texton écran** | **"Tu gères ton dépôt sur WhatsApp ?"** |
| **Voix off** | *"Ventes dans un groupe. Dettes en MP. Livraisons dans un autre groupe. Tu cherches un message d'il y a 3 semaines... tu ne le trouves plus."* |
| **Musique** | Tension, confusion |

---

### SCÈNE 2 — LES LIMITES (0:10 - 0:18)

| Champ | Détail |
|-------|--------|
| **Visuel** | Montage : |
| **Plan 1** (3s) | Le patron tape "Rechercher" dans WhatsApp, cherche "dettes". Résultat : 0 trouvés. Texton : **"Messages perdus"** |
| **Plan 2** (3s) | Photo de reçu envoyée dans le groupe, floue, illisible. Texton : **"Reçus illisibles"** |
| **Plan 3** (2s) | "500 messages non lus" en haut du groupe. Texton : **"Aucune structure"** |
| **Voix off** | *"WhatsApp n'est pas fait pour gérer un business. Les messages se perdent. Les reçus sont des photos floues. Tu ne peux rien calculer."* |
| **Transition** | Fondu |

---

### SCÈNE 3 — LA SOLUTION (0:18 - 0:32)

| Champ | Détail |
|-------|--------|
| **Visuel** | Interface DepotManager |
| **Plan 1** (4s) | Liste clients propre : Amadou (45 000 F rouge), Kodjo (120 000 F rouge), Aïcha (32 000 F rouge). Chaque ligne a : nom, solde, dernier achat. |
| **Texton écran** | **"DepotManager : chaque client a sa fiche, son solde, son historique"** |
| **Voix off** | *"Avec DepotManager, chaque client a sa fiche. Son solde. Son historique."* |
| **Plan 2** (4s) | Le patron clique sur "Amadou" → fiche complète : liste des achats, paiements, solde actuel, bouton "Envoyer rappel WhatsApp". |
| **Plan 3** (4s) | Il clique "Envoyer rappel WhatsApp" → animation : "Message envoyé ✅". Le message WhatsApp apparaît : structuré, professionnel. |
| **Texton écran 2** | **"WhatsApp reste l'outil de communication. DepotManager est l'outil de gestion."** |
| **Voix off** | *"Et tu lui envoies un rappel structuré en 1 clic — directement sur WhatsApp. WhatsApp reste l'outil de communication. DepotManager est l'outil de gestion."* |
| **Transition** | Slide |

---

### SCÈNE 4 — CTA (0:32 - 0:38)

| Champ | Détail |
|-------|--------|
| **Texton 1** | **"WhatsApp pour parler. DepotManager pour gérer."** |
| **Texton 2** | **"Essai gratuit 14 jours — depotmanager.com"** |
| **Voix off** | *"DepotManager. WhatsApp pour parler. DepotManager pour gérer."* |
