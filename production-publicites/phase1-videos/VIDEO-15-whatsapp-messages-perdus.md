## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:10)

| Champ | Détail |
|-------|--------|
| **Visuel** | Patron qui envoie un MP WhatsApp à un client. Il écrit : "Bonjour Amadou, tu me dois 45 000 F". Il envoie. |
| **Texton écran** | **"Tu envoies le rappel..."** |
| **Visuel 2** | Réponse du client : "Je n'ai rien reçu hein ! Tu mens !" |
| **Texton écran 2** | **"...le client dit qu'il n'a rien reçu"** |
| **Voix off** | *"Tu envoies le message. Le client prétend ne pas l'avoir reçu. Tu n'as aucune preuve."* |
| **Musique** | Tension, frustration |

---

### SCÈNE 2 — LES LIMITES (0:10 - 0:16)

| Champ | Détail |
|-------|--------|
| **Visuel** | WhatsApp : conversation avec le client. 200 messages. Le patron scrolle pour retrouver le message d'envoi. Impossible. |
| **Texton écran** | **"200 messages. Aucune organisation. Aucune preuve."** |
| **Voix off** | *"Dans le flot de messages WhatsApp, tu ne retrouves plus rien. Pas de liste des envois. Pas de date de lecture. Pas de preuve."* |
| **Transition** | Fondu |

---

### SCÈNE 3 — LA SOLUTION (0:16 - 0:26)

| Champ | Détail |
|-------|--------|
| **Visuel** | Interface DepotManager |
| **Plan 1** (4s) | Onglet "Messages envoyés" : liste chronologique. Ligne 1 : "Rappel envoyé à Amadou — 15/06/2026 14h32 — Montant : 45 000 F — ✅ Envoyé". Ligne 2 : "Rappel envoyé à Kodjo — 14/06/2026 10h15 — Montant : 120 000 F — ✅ Envoyé". |
| **Texton écran** | **"DepotManager : historique de tous les rappels envoyés"** |
| **Voix off** | *"Avec DepotManager, chaque rappel est enregistré. Date, heure, client, montant. Tu sais exactement ce qui a été envoyé."* |
| **Plan 2** (4s) | Le patron clique sur la ligne "Amadou" → détail : message envoyé, contenu du message, heure d'envoi. |
| **Texton écran 2** | **"Tu prouves que tu as envoyé. Le client ne peut plus nier."** |
| **Voix off** | *"Tu prouves que tu as envoyé. Le client ne peut plus nier."* |
