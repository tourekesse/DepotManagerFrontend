| **Durée** | 32 secondes |

---

## 🎬 Script de tournage détaillé

### SCÈNE 1 — L'ACCROCHE (0:00 - 0:08)

| Champ | Détail |
|-------|--------|
| **Visuel** | Patron sur son téléphone, il ouvre Excel online. L'écran est petit. Les colonnes débordent. Il zoome, dézoome sans arrêt. |
| **Texton écran** | **"Excel sur téléphone = cauchemar"** |
| **Voix off** | *"Excel n'est pas fait pour le téléphone. Les colonnes débordent. Tu zoomes, tu dézoomes. Tu ne vois jamais tout."* |
| **Musique** | Tension, frustration |

---

### SCÈNE 2 — LES LIMITES (0:08 - 0:16)

| Champ | Détail |
|-------|--------|
| **Visuel** | Montage : |
| **Plan 1** (3s) | Le patron essaie de modifier une cellule → le clavier couvre la moitié de l'écran. Texton : **"Modifier = galère"** |
| **Plan 2** (3s) | Il essaie de sauvegarder → "Synchronisation en cours..." → échec. Texton : **"Sauvegarder = aléatoire"** |
| **Plan 3** (2s) | Il attend, frustré. Texton : **"Tu attends d'être au bureau"** |
| **Voix off** | *"Tu ne peux rien modifier proprement. La sauvegarde est incertaine. Tu attends d'être au bureau."* |
| **Transition** | Fondu |

---

### SCÈNE 3 — LA SOLUTION (0:16 - 0:26)

| Champ | Détail |
|-------|--------|
| **Visuel** | Téléphone avec DepotManager (PWA) |
| **Plan 1** (3s) | Écran d'accueil : gros boutons "Nouvelle vente", "Stock", "Clients", "Livraisons". Interface propre, pensée pour le mobile. |
| **Texton écran** | **"DepotManager : conçu pour le téléphone"** |
| **Voix off** | *"DepotManager est conçu pour le téléphone. Gros boutons, navigation simple, tout est à portée de main."* |
| **Plan 2** (4s) | Le patron ajoute une vente en 3 clics : 1) Recherche produit, 2) Ajout au panier, 3) Validation. Rapide, fluide. |
| **Plan 3** (3s) | Il sort du dépôt, téléphone en main, il gère depuis la rue. |
| **Texton écran 2** | **"Tu gères ton dépôt depuis n'importe où"** |
| **Voix off** | *"Tu gères ton dépôt depuis n'importe où. Pas besoin de bureau. Pas besoin de PC."* |
| **Transition** | Slide |

---

### SCÈNE 4 — CTA (0:26 - 0:32)

| Champ | Détail |
|-------|--------|
| **Texton 1** | **"Ton dépôt dans ta poche. Pas dans ton bureau."** |
| **Texton 2** | **"DepotManager — Essai gratuit 14 jours — depotmanager.com"** |
| **Voix off** | *"DepotManager. Ton dépôt dans ta poche."* |
